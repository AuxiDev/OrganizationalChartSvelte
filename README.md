# Svelte Organizational Chart

Welcome to **Svelte Organizational Chart** – the intuitive and customizable solution for visualizing hierarchies, teams, and relationships directly on your website. Whether you're mapping out team structures, company hierarchies, or complex relationships, this easy-to-use, feature-packed component has you covered!

## 🚀 Features

- **🔧 Editable Mode**: Modify your chart on the fly! Right-click any person to add, remove, or edit their details with ease.
- **🌟 User-friendly Interface**: Simple, clean, and intuitive interface for seamless chart editing and viewing.
- **🌱 Multiple Line Styles**:
  - **Connected**: Neatly connects persons within the same level.
  - **Tree**: A classic tree structure, ideal for hierarchical relationships.
  - **List**: A straightforward vertical list view for clear, organized structures.
- **📥 Download as SVG**: Need to share or embed your chart elsewhere? Download it as a high-quality SVG.
- **🎨 Fully Customizable Nodes**: Control every aspect of your chart! Adjust line styles, colors, and node layout to match your brand.
- **🔄 Drag & Drop Support**: Easily rearrange people or move them to new nodes. Drag them to the + icons to add then as a new node.
- **↩️ Undo & Redo**: Made an accidental change? Undo and redo your actions without breaking a sweat.
- **📂 Export & Import**: Save your chart or import existing data so you can work on multiple charts.
- **🧩 No Extra Libraries**: Built entirely with Svelte & SvelteKit – no external libraries required.

## 📅 What’s Coming Next?

We’re just getting started! Upcoming features include:

- **Q4L Features**: Expect more enhancements for better performance and user experience.
- **Advanced Node Options**: New features to further customize how nodes and connections look.

## 🚫 Unsupported Actions

Currently, the following features are not supported:

- **Nesting Lists within Lists**: For the moment, nesting lists inside one another isn’t available.
- **Unconventional Tree Structures in Lists**: Some unconventional layouts (such as complicated tree structures) might not work well.
